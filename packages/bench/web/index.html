    Sections

    All twenty base slots are labelled now, and the byte accounting reaches every byte of a user config. What a section is for is in docs/config-format.md rather than in this table.

    What a config is for

    Reads a config the lab already holds, so this needs no remote on the desk. Devices, activities, and what each button sends: the same call FreeHarmony will make.

    Devices

    The repeat column is how often a held key sends again, in milliseconds. Holding a key replays the code's second duration block for as long as it is down, so that block's own length is the interval. Findings section 127.

    Activities

    Screens

    Drawn from the config's own bytes: the pictures, the glyphs and the screen program that places them. Findings section 129. A page marked with a branch count switches on the state of the remote, so what you see is the first of several appearances. Pick a page to see the keys that belong to it.

    Buttons that send a code

    A code has no name: it is a device and an index. A page binding is a soft key on a screen and a set binding is a hard key while an activity runs, which is where the volume keys are. Every one is a press bar a handful of enter and leave handlers, and a binding that sends more than one code is a macro.
