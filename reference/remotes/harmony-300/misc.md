# Harmony 300: miscellaneous

**The rule for this file**: a note goes here only when it fits none of the other nine files. If the same
kind of note would appear in the `misc.md` of several models, it deserves a file of its own in every
model folder instead, and `reference/remotes/README.md` and the generator's test get updated with it.

## Logitech's service and a made up serial

A registration for a Harmony 300 with a synthetic serial was refused by `ValidateRemote`, which is how this
project learned that the service validates a serial, Logitech's service, section 136.

## Predictions before each read

Both reads of a 300 were predicted in writing before they were taken,
`docs/predictions-arch16-harmony-300.md` and `docs/predictions-arch16-harmony-300-programmed.md`, and
sections 264 and 265 record which held.
