# Harmony 515: keys

**The Harmony 515 has the Harmony 525's face**, key for key, with three differences: the model number
above the screen, and the Mute and Prev keys, which carry a crossed out speaker and a return arrow where
the 525 prints the words.[^unchecked] So the drawing takes every shape from the 525's, and the scan code
candidates of the four soft keys come with it; those are read in the 525's firmware, and whether the
515's keypad matrix is the same is not checked.[^unchecked]
