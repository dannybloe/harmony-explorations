## The software the manual names

The manual describes Logitech's classic **Harmony Remote Software**, and Windows 2000, XP and Vista and
Mac OS X 10.3 as the supported platforms, Logitech's manual. Logitech's current Harmony Desktop does not
recognise the model, section 135. Concordance writes it, and lists arch 9 configuration update as working,
section 267.
