# Harmony 525: miscellaneous

**The rule for this file**: a note goes here only when it fits none of the other nine files. If the same
kind of note would appear in the `misc.md` of several models, it deserves a file of its own in every
model folder instead, and [the reference's README](../../README.md) and the generator's test get
updated with it.

## The software the manual names

The manual describes Logitech's classic **Harmony Remote Software**, and Windows 2000, XP and Vista and
Mac OS X 10.3 as the supported platforms.[^x-manual] Logitech's current Harmony Desktop does not recognise
the model.[^s135b] Concordance writes it, and lists architecture 9 configuration update as
working.[^x-concordance]

## A configuration's language

A 525's screens are in the language its configuration was compiled for, and no field says which, as on
every model, [screens](../../config-format/screens.md).[^s149]
