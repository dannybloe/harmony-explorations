# Harmony 600: miscellaneous

**The rule for this file**: a note goes here only when it fits none of the other nine files. If the same
kind of note would appear in the `misc.md` of several models, it deserves a file of its own in every
model folder instead, and `reference/README.md` and the generator's test get updated with it.

## The software the manual names

The 600's manual describes Logitech's older desktop software, the **Harmony Remote Software**, with its
Activities, Devices and Remote Settings tabs[^x-manual]. Today's client for this model is MyHarmony, whose
settings for the 600 are in [features.md](features.md); where a step in the manual and MyHarmony
disagree, the manual describes the older generation of the software.

[^x-manual]: Stated by Logitech, in the manual. [The Harmony 600 user manual](https://www.manualslib.com/manual/634914/Logitech-Harmony-600.html)
