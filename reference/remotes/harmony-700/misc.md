# Harmony 700: miscellaneous

**The rule for this file**: a note goes here only when it fits none of the other nine files. If the same
kind of note would appear in the `misc.md` of several models, it deserves a file of its own in every
model folder instead, and `reference/remotes/README.md` and the generator's test get updated with it.

## The published pair of configurations

Two configurations of one Harmony 700, posted publicly by their owner with one documented change between
them, 979184 and 979242 bytes, are the only controlled pair in the corpus, section 16 and
`reference/checksums.md`. **Their build timestamps order them the opposite way round from the owner's
stated direction of the change**, and that is unresolved, so a timestamp is not used to order two
configurations of the same remote, section 21 and `CLAUDE.md` key facts.

## The software the manual names

The 700's manual describes Logitech's older desktop software, the **Harmony Remote Software**, Logitech's
manual. Today's clients for this model are MyHarmony and Harmony Desktop; section 295 records how each
behaved with a 700 in safe mode.
