# Harmony 720: behaviour

How a Harmony 720 behaves for the person holding it. What activities and device mode are, on every
Harmony, is [how a Harmony works](../../how-a-harmony-works.md).

**Nothing about this model's own behaviour has been measured here.** No unit has been held, and a
configuration does not say how the remote enters device mode or what it shows on start.[^unchecked] Its
start is the platform's: the 720's application runs the start check the 880's and 885's do, with its working
addresses moved, [the platform's firmware](../../architectures/harmony-880-885/firmware.md#the-harmony-720s-images).[^t-885-start]

## Not checked

* How device mode is entered and left, the screens on start, on the cable and with a low battery, the help
  and the timers.[^unchecked]
