# Harmony 785: miscellaneous

**The rule for this file** is the same as every model folder's: a note goes here only when it fits none of the
other files, and a kind of note that recurs gets a file of its own.

## Names

* **The folder is the 785's alone.** The model table names the Harmony 720 its regional twin, and the 785's
  application is the 720's 4.5 with ten bytes changed, but the 785 has teletext keys the 720 does not, [the README](README.md).[^t-printing-720]
  The platform's names, Espresso among them, are in [the architecture's misc page](../../architectures/harmony-880-885/misc.md).
