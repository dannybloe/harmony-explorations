# Harmony 885: miscellaneous

**The rule for this file** is the same as every model folder's: a note goes here only when it fits none of
the other files, and a kind of note that recurs gets a file of its own.

## Names

* **One folder for two names.** The Harmony 880 and 885 are one remote under two regional names, skins 15
  and 17, and the folder is named for the 885.[^x-forum-table][^s114] The platform's names, Espresso among
  them, are in [the architecture's misc page](../../architectures/harmony-880-885/misc.md).
