# Harmony 890: miscellaneous

**The rule for this file** is the same as every model folder's: a note goes here only when it fits none of
the other files, and a kind of note that recurs gets a file of its own.

## Names

* **One folder for two names.** The Harmony 890 and 895 are one remote under two regional names, skins 19
  and 23, and the folder is named for the 890.[^x-forum-table][^s182] The platform's names, Cappuccino
  among them, are in [the architecture's misc page](../../architectures/harmony-890-895/misc.md).
