# Harmony One: miscellaneous

**The rule for this file**: a note goes here only when it fits none of the other nine files. If the same
kind of note would appear in the `misc.md` of several models, it deserves a file of its own in every
model folder instead, and `reference/README.md` and the generator's test get updated with it.

## The software the manual names

The One's manual describes Logitech's older desktop software, the **Harmony Remote Software**, for every
setting a person changes away from the remote[^x-one-manual]. Logitech's later software and which of it
still programs this model is [the clients page](../../logitech/clients.md).

[^x-one-manual]: Stated by Logitech, in the manual. [The Harmony One user guide](https://secure.logitech.com/assets/44645/13/harmonyone-user-guide.pdf)
